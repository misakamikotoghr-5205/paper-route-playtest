## 复核和再生成

在项目根目录运行，无需安装依赖：

```sh
node docs/evidence/verify.mjs
```

验证器只读检查当前源码与生成器 SHA、产物 SHA、四条真实通关路线、完整步骤记录、原样缺陷报告与严格版对照。它不会因后续仅提交文档造成 HEAD 改变而误报；依据是记录的源码字节。若核心源码或生成器改变，应保留旧证据并重新生成、审阅新的一批。

建议再生成到一个新目录，保留本次历史文件：

```sh
node docs/evidence/generate.mjs --out ./evidence-rerun
node docs/evidence/verify.mjs ./evidence-rerun
```

不带 `--out` 会重写本目录生成的 JSON、日志与 manifest。生成时间按真实运行时刻记录；两次执行的通关 JSON、缺陷 JSON 和严格对照应字节一致，时间字段与带时间的日志会改变。再生成不会改核心代码、`dist`、上传 ZIP 或报名状态。
